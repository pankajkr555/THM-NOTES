# TryHackMe: Pre-Security Path Notes

## 🛡️ Module 1: Introduction to Cyber Security
*   **Offensive Security (Red Team):** Finding vulnerabilities by thinking like a hacker before malicious actors do. (e.g., Penetration Testing).
*   **Defensive Security (Blue Team):** Protecting systems, monitoring networks, and responding to attacks. (e.g., SOC Analyst).
*   **Careers in Cyber:** Various roles including Penetration Tester, SOC Analyst, Security Engineer, and Incident Responder.

## 💻 Module 2: Computer Fundamentals
*   **Computer Types:** Desktops, Laptops, Servers, and IoT (Internet of Things - like smart fridges/cameras).
*   **Inside a Computer System (Hardware):**
    *   **Motherboard:** The main circuit board that connects everything.
    *   **CPU:** The brain (processes instructions).
    *   **RAM:** Short-term memory (forgets when power is off).
    *   **Storage (HDD/SSD):** Long-term memory (keeps data forever).
    *   **PSU:** Power Supply Unit.

## ⚙️ Module 3: Operating Systems (OS) Basics
*   **Operating Systems: Introduction:** The software that manages hardware and software resources. Examples: Windows, Linux, macOS.
*   **Windows Basics:** Learned about NTFS file system, user accounts, and system settings.
*   **Linux CLI (Command Line Interface) Basics:**
    *   Unlike Windows GUI, Linux is heavily terminal-based.
    *   Key Commands:
        *   `pwd`: Print working directory (shows current folder).
        *   `ls`: List files and directories.
        *   `cd`: Change directory.
        *   `cat`: Read file contents.
        *   `grep`: Search for text inside files.

## 🌐 Module 4: Network Fundamentals
*   **What is Networking?**
    *   **IP Address:** Logical identifier (can change).
    *   **MAC Address:** Physical identifier (hardcoded in hardware).
    *   **Ping (ICMP):** Used to test connectivity between devices.
*   **Intro to LAN (Local Area Network):**
    *   **LAN:** Network in a small area (home/office).
    *   **ARP (Address Resolution Protocol):** Finds the MAC address of a device using its IP address.
    *   **DHCP:** Automatically assigns IP addresses to devices.
*   **OSI Model:** The 7 layers of networking (Physical, Data Link, Network, Transport, Session, Presentation, Application). Essential for understanding how data travels.
